# Phase 3: RAG Answer Generation

> **Status**: ✅ Complete  
> **Date**: August 2026

This document describes the implementation of Phase 3 — RAG (Retrieval-Augmented Generation) answer generation using Groq API.

---

## Overview

Phase 3 adds the ability to ask natural language questions about climate adaptation and receive grounded, cited answers generated by an LLM. The system retrieves relevant passages from the indexed climate literature, then uses Groq's fast LLM inference to synthesize a comprehensive answer with inline citations.

---

## New Files Created

### `generation.py`
The core RAG answer generation module.

**Key Functions:**
| Function | Description |
|----------|-------------|
| `generate_answer()` | Main pipeline: retrieve → build context → generate answer |
| `ask()` | Convenience function that generates and prints the answer |
| `print_answer()` | Pretty-print formatted output with citations |
| `_build_context()` | Format retrieved passages for LLM context |
| `_build_system_prompt()` | Climate CoPilot persona and guidelines |
| `_build_user_prompt()` | Combine question with retrieved passages |

**Features:**
- Lazy-loaded Groq client for efficiency
- Configurable LLM model selection
- Token usage tracking
- Inline citation generation ([1], [2], etc.)
- Source reference listing

### `.env`
Stores the Groq API key securely (gitignored).

```
GROQ_API_KEY=your_api_key_here
```

### `.env.example`
Template file for other developers.

### `.gitignore`
Security patterns to prevent committing secrets and cache files.

## Usage Examples

### Basic Question
```bash
python main.py ask -q "How will climate change affect wheat production?"
```

### With Verbose Output
```bash
python main.py ask -q "What are adaptation strategies for drought?" -v
```

### Show Retrieved Passages
```bash
python main.py ask -q "Impact of temperature on crop yields" --show-passages
```

### Filter by Source
```bash
python main.py ask -q "IPCC findings on agriculture" --source IPCC
```

### Use Different Model
```bash
python main.py ask -q "Your question" --model llama3-8b-8192
```

### All Options
```bash
python main.py ask -q "Your question" \
    -k 10 \
    --source FAO \
    -m hybrid \
    --model llama-3.3-70b-versatile \
    -v \
    --show-passages
```

## System Prompt Design

The LLM is instructed to act as "My Climate CoPilot" with these guidelines:

1. Answer questions based **ONLY** on provided context passages
2. Clearly state when information is missing
3. Use inline citations `[1]`, `[2]`, etc.
4. Be specific about locations, crops, and timeframes
5. Explain scientific concepts accessibly
6. Acknowledge uncertainties in climate projections
7. Structure longer answers with headings

## Configuration

### Environment Variables

| Variable | Description | Required |
|----------|-------------|----------|
| `GROQ_API_KEY` | Your Groq API key from console.groq.com | Yes |

### Default Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `top_k` | 5 | Number of passages to retrieve |
| `retrieval_mode` | hybrid | Retrieval strategy (dense/bm25/hybrid) |
| `model` | llama-3.3-70b-versatile | Groq model |
| `temperature` | 0.3 | LLM temperature (lower = more focused) |
| `max_tokens` | 2048 | Maximum response length |
